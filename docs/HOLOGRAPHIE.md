# Brillance et centrage des noms

Les noms utilisent désormais les coordonnées intérieures de chacun des sept cartouches maîtres ; le centrage précédent utilisait une seule zone pour tous les cadres. Les surnoms restent dans les caractéristiques.

Les cartes rares et supérieures portent une couche irisée, un balayage métallique et des étoiles à quatre branches. Intensité maximale du balayage par rareté : 0,24 / 0,36 / 0,50 / 0,65 / 0,85. L’album et les résultats utilisent une finition fixe sans boucle ; le visualiseur et la révélation activent le balayage, sensible à l’inclinaison dans le visualiseur. Les cartes mythiques ajoutent une constellation ; les divines portent davantage d’étoiles et des rayons célestes.

À l’ouverture, les auras tournent lentement, les particules jaillissent après les révélations et l’éclairage est renforcé pour les plus hautes raretés. Aucun flash blanc plein écran. Les animations s’arrêtent en arrière-plan ; la réduction des animations conserve un reflet fixe. Aucune image officielle, sauvegarde, probabilité ou attribution n’est modifiée.

Validation : typage strict, 44 tests et contrôles des ressources, parcours navigateur adapté (roue, visualiseur, album, ouverture de sept cartes, téléphone/tablette), exports iOS et Android. Le rendu animé et les performances sur appareil restent à valider dans Expo Go.
