Le nom de fichier source Phbe est conservé ; l’interface utilise Phœbé, issu du catalogue. Les identifiants fournis résolvent les associations sans confirmation manuelle. Les peintures valides utilisent les cadres maîtres existants et possèdent chacune un point de cadrage explicite. Le zoom conserve le tableau entier, sans étirement. Les décors peints restent opaques ; les cadres gardent leur transparence extérieure.

Le registre est partagé par les cartes de l’album, les révélations, les résultats, le visualiseur et le zoom. Aucun texte de catalogue, solde, reçu, rareté ou quantité n’est modifié. Les noms seuls restent centrés dans les cartouches ; les surnoms restent dans les caractéristiques.

Les variantes de Cronos OLY-052/058 et de Gaïa OLY-053/059 utilisent leurs peintures distinctes et leurs emplacements existants dans le catalogue. Leurs surnoms restent dans les caractéristiques, sans réintroduction dans les cartouches.

59 peintures sont désormais disponibles : 30 pour Les Maîtres de l’Olympe et 29 pour L’Ère des Titans. Il reste Éos OLY-049 à renvoyer, 30 illustrations des Héros et 30 des Créatures à fournir. Ces 61 cartes conservent la mention Illustration à fournir.

Le contrôle des illustrations vérifie les quatre INDEX des Titans, l’index initial des Olympiens, les associations catalogue/index/registre, les dimensions, le ratio 5:7 et les SHA-256 des 58 PNG valides suivis. Zeus divin utilise sa source JPG préexistante. Le fichier assets/illustrations.unavailable.json conserve le numéro, l’archive d’origine, l’empreinte et le motif de rejet d’Éos. Le contrôle signale séparément OLY-049 en attente et vérifie que la source tronquée n’est associée à aucune carte affichée. Les validations globales, le cadrage et les exports natifs sont exécutés séparément lors de l’intégration ; le rendu sur iPhone reste à confirmer dans Expo Go.
