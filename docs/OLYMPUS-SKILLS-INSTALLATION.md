# Installation — OLYMPUS Codex skills

1. Unzip this package.
2. Copy the `.agents/skills/` folder into the ROOT of your existing OLYMPUS Git repository, preserving the folder structure.
3. Open the included `AGENTS.md` and merge its instructions into your existing root `AGENTS.md` if one exists. Do not overwrite your existing project instructions blindly.
4. Commit the additions and reopen your Codex project/session if the skills are not detected immediately.
5. In Codex, try: `Utilise $olympus-card-designer pour auditer l'affichage de mes cartes, sans modifier le code.`
6. Then: `Utilise $olympus-game-qa pour vérifier les tests existants et les flux critiques d'OLYMPUS.`

These are instruction-only skills: they do not add artwork, install libraries, change code, or assume a particular stack. Run them against your real repository and catalog for project-specific results. The `.agents` directory may be hidden in file explorers; enable display of hidden files if needed.
